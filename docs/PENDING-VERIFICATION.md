## P1 —— 功能正确性

### 3. 拖动窗口边缘 → guest 分辨率跟随
**背景**:命令行触发的 `setres` 已实测全链路成功(帧缓冲自动重映射)。
但**用鼠标拖窗口**这条路径多了一层 250ms 防抖与 `guestReady`/`suppressUIInfo` 判据。

**怎么验**:拖动窗口四角,松手后约 1 秒 guest 分辨率应跟随,画面保持锐利而非被拉伸。

**已知并已处理**:guest 驱动只接受它暴露的 23 个模式,任意尺寸返回 `-2`。
宿主侧现在会自动吸附到「不小于窗口的最小模式」。
所以画面可能略大于窗口后被缩小 —— 这是有意的取舍(缩小比放大清楚)。

### 4. 键盘输入的完整性
**怎么验**:组合键(Ctrl+C / Cmd 系列)、方向键、功能键。

**已知**:中文 IME 会转换按键。安装流程现在默认英文输入法,
但切到中文后自动化仍会受影响 —— 这对真实用户是正确行为,不是 bug。

### 5. 音频
`intel-hda` + `hda-output` + CoreAudio 已配上,但我听不到声音。

### 5b. 设置面板里的磁盘项
**怎么验**:资源库里对虚拟机点「设置…」。

- 已挂起的机器:磁盘项灰掉,下面写着「虚拟机已挂起。开机后在系统里关机…」
- 从 guest 里关机后再打开:可以调,最小值就是现在的大小,调大后出现「磁盘只能扩大…」的提示
- 保存后下次开机,guest 里的 C: / 根分区变大(宿主日志 `[磁盘] 系统分区已扩展`)
